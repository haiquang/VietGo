# PRODUCT — VietGo

## Overview
**VietGo** is a native macOS Vietnamese input engine (`Telex` and `VNI`) engineered for low latency, zero-underline inline composition, and seamless compatibility across developer tools, browsers, launchers, and productivity apps.

## Target Audience
- Vietnamese software engineers, writers, and macOS power users who switch rapidly between Vietnamese prose and English code identifiers, acronyms, URLs, and terminal commands.

## Primary Surface & Mode
- **Mode:** `Operate` (utility preferences, shortcut management, macOS Accessibility permission diagnostics, and live typing verification).
- **Window Dimensions:** `620 × 520` non-scrolling primary shell with persistent status header, 4 structured tabs (`Bộ gõ`, `Thông minh`, `Phím tắt`, `Gõ thử`), and automatic Light/Dark macOS appearance support.
- **Menu Bar Surface:** Native macOS template icon (`22 × 16 pt`, filled `"V"` pill when Vietnamese is active, stroked `"E"` pill in English mode) paired with an `NSMenu` for instant switching.
